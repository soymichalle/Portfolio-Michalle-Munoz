# Portafolio Personal

Portafolio web personal desarrollado para presentar mi perfil profesional, proyectos, habilidades y experiencia en las áreas de ingeniería de sistemas, desarrollo de software e ilustración digital.

Un espacio para integrar tecnología, creatividad y diseño, mostrando mi evolución profesional y los proyectos en los que he trabajado.

## ✨ Secciones

* Banner.
* Proyectos de desarrollo de software.
* Sobre mí.
* Habilidades técnicas y creativas.
* Contacto y redes profesionales.

## 🛠️ Tecnologías

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Manipulación del DOM
